# Наш план — Telegram Mini App, прототип

Это первая клиентская версия без собственного backend-сервера.

## Что уже есть
- запуск внутри Telegram Mini App;
- определение пользователя Telegram;
- локальное сохранение данных;
- участник Евгений;
- кнопка приглашения Тани;
- добавление событий на сегодня;
- базовый список участников;
- адаптация под светлую/тёмную тему Telegram.

## Что пока НЕ работает как общая синхронизация
Данные сохраняются в локальном хранилище устройства. Поэтому изменение у Евгения не появится автоматически на устройстве Тани.

Следующим этапом сделаем механизм пространства/приглашения и затем выберем способ передачи изменений через Telegram без отдельного backend.

## Запуск
1. Создай бота через @BotFather.
2. Для Mini App нужен HTTPS URL.
3. Загрузить содержимое этой папки можно на статический хостинг (например GitHub Pages или Cloudflare Pages).
4. В @BotFather назначить URL Mini App.
5. Открыть приложение из Telegram.

ВАЖНО: токен бота не вставляй в HTML/JS и никому его не отправляй.
